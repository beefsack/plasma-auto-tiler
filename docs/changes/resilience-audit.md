# Resilience audit (source-only, 2026-09-26)

## Scope and standard

- Production `kwin/src`, `crates/*/src`, and the native effect where relevant, at `9549721`. No live testing or source changes. Findings below are source-verified; runtime duration and frequency are not established.
- Principle: only an actual all-functionality hard failure may terminate permanently; otherwise log and recover, converge to complete per-domain observation, and treat client/window changes as normal. Severity: **indefinite** (tiling blocked until external intervention), **user action** (degraded until a new action), **self-healing** (bounded or automatically refreshed).
